# 鏡 (Mirror)

iPhone の Safari で動くシンプルな鏡アプリ（Web アプリ）。

- 内カメ / 外カメ 切替
- 写真撮影（内カメは鏡で見たまま左右反転で保存）
- 録画（映像のみ・**マイク不使用**なので音楽などの再生は止まりません）
- 画面タップでボタンを隠す
- 「保存」→「画像を保存 / ビデオを保存」で写真アプリへ

## 使い方
1. GitHub の Settings → Pages で、このブランチ / `/(root)` を公開
2. iPhone の Safari で公開 URL を開き、カメラを許可
3. 共有 → 「ホーム画面に追加」でアプリのように全画面で使えます

※ カメラは https でないと動きません（GitHub Pages は https）。
