# Web

iPhone の Safari で動くシンプルな鏡アプリ（見た目は普通のブラウザ）。

| 操作 | 動作 |
| --- | --- |
| 起動時 | ブラウザのスタートページ（お気に入り）が表示される |
| › | 鏡を表示 |
| ‹ | スタートページに戻る |
| 共有 | 写真（内カメは鏡で見たまま左右反転で保存） |
| 本 | 録画開始／停止（映像のみ・マイク不使用なので音楽は止まらない） |
| タブ | 内カメ／外カメ切替 |
| アドレスバーの ⟳ | クロ画面（真っ黒）。画面をダブルタップで戻る |
| アドレスバー／お気に入り | 本当に検索できる（Safari で開く） |

ホーム画面に追加して使うと、Safari の本物のアドレスバーが出ないので普通のブラウザに見えます。
